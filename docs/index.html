TLDR: We identify a shared 180-feature analogical reasoning circuit in Gemma-2-2B that generalizes across geographic and semantic analogies, including a dedicated L5 SAE#5793 feature labeled simply "analogies" — direct evidence of a reusable relational reasoning primitive.


Abstract

We present the first mechanistic analysis of analogical reasoning in Gemma-2-2B using Sparse Autoencoder (SAE) attribution graphs. By generating and comparing five attribution graphs across structurally distinct analogical prompts — covering geographic analogies (Paris:France::Berlin:?, Rome:?, Tokyo:?) and semantic role analogies (Doctor:hospital::teacher:?, Fish:water::bird:?) — we identify a shared analogical reasoning circuit comprising 180 features active across all five prompts and 510 features active across at least three.

We discover dedicated analogy-encoding features at layers 5, 8, 9, and 13, including a feature at Layer 5 labeled literally as "analogies" and a Layer 8 feature encoding "analogies or comparisons" appearing across all graphs with high influence. Early layers (0–4) contain structural template features tracking the "X is to Y as Z is to" pattern, while mid-to-late layers (5–13) house increasingly semantic representations of the relational structure. The circuit spans all 26 transformer layers and exhibits cross-domain generalization, with the same core features activating for both geographic and semantic role analogies.

1. Introduction

Analogical reasoning — the ability to recognize and complete structural relationships between concepts — is a foundational cognitive ability underlying scientific discovery, language understanding, and problem solving. The classic analogy task, "Paris is to France as Berlin is to ____," tests whether a model can identify the capital-city relationship abstractly and apply it to a new country. Large language models exhibit striking competence on such tasks, yet the internal computational mechanisms remain poorly understood.

Figure 1. The analogy task. Given the relationship between Paris and France, the model must recognize the capital-of relation and apply it to a new pair. This requires relational abstraction, not mere fact retrieval.

Mechanistic interpretability research has made significant progress in understanding factual recall circuits (Meng et al. 2022), indirect object identification (Wang et al. 2022), and syntactic processing (Conmy et al. 2023). However, analogical reasoning presents a distinct challenge: it requires not merely retrieving a stored fact, but recognizing a relational structure and applying it compositionally to novel inputs. How does a transformer represent "capital of" as a relationship, separate from the specific cities and countries involved?

Research Questions

  1. Does Gemma-2-2B employ a shared circuit for analogical reasoning, or does it use different mechanisms for different analogy types?
  2. Which SAE features are most consistently activated across diverse analogical prompts?
  3. Are there interpretable, semantically meaningful features that encode the abstract relational structure of analogies?
  4. How is the analogical computation distributed across transformer layers?

2.2 Attribution Graph Generation

Attribution graphs were generated using the Neuronpedia API (/api/graph/generate) with Gemma-2-2B and the gemmascope-transcoder-16k SAE — a 26-layer cross-layer transcoder with 16,384 features per layer.

Each graph request returns a URL to an AWS S3 object containing the full attribution graph in JSON format, including nodes (SAE feature activations with layer, index, influence score, and activation magnitude) and directed edges (attribution scores). Graphs were downloaded and loaded into NetworkX DiGraph objects for analysis.

2.3 Feature Identification and Cross-Graph Analysis

Cross-graph feature overlap was computed by finding features — identified by (layer, SAE index) pairs — that appear consistently across multiple graphs. Three overlap thresholds were analyzed: ≥3/5, ≥4/5, and 5/5 graphs. The top 25 most recurring features were labeled using the Neuronpedia feature explanation API.

A key technical finding: the correct API endpoint for gemmascope-transcoder-16k requires a layer-prefixed SAE identifier (e.g., 4-gemmascope-transcoder-16k for layer 4) rather than the global SAE name.

2.4 Causal Validation via Feature Steering

The attribution graph analysis above identifies which features participate in producing the prediction, but not whether those features are causally responsible. A feature with high attribution weight may be a passenger riding alongside the actual mechanism rather than driving it. To establish causation, we intervene on the 180-feature shared analogical circuit (§2.3 — the features appearing in ≥5 nodes across the five analogy attribution graphs) with the Neuronpedia /api/steer endpoint. A methodological point shapes the design: steering at strength −20 is an effective −80 per-feature intervention (see parameters below), large enough that ablating any sizable feature set derails the model. Bare necessity ("the output changed") is therefore non-discriminating, so our primary test is a matched contrast, not a single ablation:

  1. Circuit necessity, matched against a null (primary). For each of the five analogy prompts we run two ablations of identical size (180 features) and strength (−20): (a) all 180 circuit features, and (b) 180 random non-circuit features drawn from the same prompt's graph. The evidence is the contrast between them — whether removing the circuit breaks the task differently from removing a matched random set. Reported in §3.7.1; per-prompt detail in Appendix A.6.
  2. Internal structure (individual necessity). On the Berlin prompt, suppress each of the 180 features one at a time to locate the individually load-bearing features within the set. Reported in §3.7.1; full table in Appendix A.2.
  3. Phase-level suppression. Collectively suppress each phase's representative features (§3.3) across all five prompts to test the three-phase architecture. Reported in §3.7.2–§3.7.3.
  4. Single-feature side-tests (supplementary). A sufficiency probe (boost the highest-influence hub feature) and an individual non-circuit specificity scan. These probe single features rather than the circuit and are reported in Appendix A.4 and A.3.

API parameters: modelId: "gemma-2-2b", layer: "{N}-gemmascope-transcoder-16k", strength_multiplier: 4, temperature: 0, seed: 42. The strength_multiplier: 4 means the effective per-feature steering magnitude is 4× the bare strength value — i.e., "strength −20" is an effective −80 intervention into the feature's decoder direction. We report bare strength throughout for consistency with the API call; readers comparing to other steering libraries should multiply by 4. Results are organized as a claim-by-claim ledger in §3.7, with full per-prompt and per-feature data in Appendix A.

3.3 Evidence for Multi-Step Analogical Reasoning

We provide evidence that Gemma-2-2B performs genuine multi-step analogical reasoning internally. The model does not merely pattern-match the surface form of the analogy prompt — instead, dedicated analogy-concept features activate at specific layers, each contributing a computationally distinct role. This section walks through the attribution graph as a causal narrative.

Core finding: The attribution graph reveals a three-phase computational process: (1) structural template parsing at early layers, (2) analogy concept recognition at mid layers, and (3) relational integration and output formation at deeper layers. The same three-phase sequence activates for both geographic and semantic role analogies — providing evidence for a domain-agnostic relational reasoning mechanism.

Validation with Inhibition Experiments

The structure of the attribution graph makes a strong prediction: inhibiting Phase 2 features — particularly L5 SAE#5793 ("analogies") and L8 SAE#13766 ("analogies or comparisons") — should degrade the model's ability to complete the relational structure, while leaving factual recall circuits intact. This prediction is consistent with the finding that these features are absent from the capital city factual recall circuit (see §4.4), which solves a different task using different mechanisms. Causal steering results (§3.7) confirm the relational-degradation half of this prediction across all five prompts: full suppression of the 180-feature shared circuit produces a distinctive, reproducible failure mode (§3.7.1), and collective Phase 2 suppression specifically — leaving Phase 1 intact — causes capital analogies to revert to the source-pair country "France" (§3.7.3), the failure mode predicted if Phase 2 implements relational transfer. The "leaving factual recall intact" half of the prediction is consistent with the structural divergence in §4.4 but was not directly tested by steering on the capital-recall prompt.

Feature Swapping Prediction

An analogous experiment to Anthropic's feature swapping (2025) would involve injecting the Phase 1 structural template features from a different analogy (e.g., from the teacher prompt) into the Berlin prompt at the Phase 2 boundary. If the circuit is genuinely modular — if Phase 2 reads relational structure from Phase 1 outputs rather than from the raw input — then swapping the structural template should redirect the analogy completion. This remains to be tested with direct model access.

3.7 Causal Validation via Feature Steering

Everything above is correlational: attribution graphs tell us which features are active and influential when the model answers, not whether those features cause the answer. A highly active feature may be a passenger riding alongside the computation rather than a driver of it (§2.4). This section intervenes — suppressing and boosting features with the Neuronpedia /api/steer endpoint — to ask, claim by claim, whether the paper's structural findings are causally real.

How to read every result in this section. One methodological fact governs the interpretation throughout. Steering at strength −20 is an effective −80 intervention per feature (§2.4) — a large perturbation. At that magnitude, removing any sizable feature set will derail the model, so the bare observation "the output changed" (necessity) is necessary but not sufficient evidence that a particular circuit is responsible. The discriminating evidence is of two kinds: (i) a matched contrast — does ablating the circuit break the task differently from ablating a size- and strength-matched random set? — and (ii) a predicted failure mode — does the model fail in the specific way the feature's claimed role implies? We rely on these throughout, not on necessity alone.

Roadmap. §3.7.1 tests whether the 180-feature shared circuit (§2.3) is causally load-bearing as a whole, using the matched-contrast design across all five prompts. §3.7.2–§3.7.3 test a separate claim — that the circuit is internally organized into the three phases of §3.3 — using phase-level suppressions. §3.7.4 collects the outcomes into a claim-by-claim ledger that states, for each structural finding in the paper, exactly what the steering evidence does and does not establish.

3.7.1 Is the Recurring Circuit Causally Load-Bearing? (Necessity & Specificity)

What we are testing. §2.3 defined the 180-feature shared circuit by recurrence — these features reappear across all five analogy attribution graphs. Recurrence is a correlational signal. The causal question is whether this set is what the model actually uses to produce the answer, or whether the recurring features are passengers that ride alongside the computation without driving it. This subsection answers that question.

Why one ablation is not enough. The obvious test — suppress the circuit and check whether the answer changes (necessity) — is necessary but not sufficient evidence. Steering at strength −20 is an effective −80 intervention per feature (§2.4); at that magnitude, removing any 180 features perturbs the residual stream enough to derail generation. "The answer changed" therefore does not, on its own, distinguish the circuit from an arbitrary feature set. To make the necessity result mean something we pair it with a matched null control: for each prompt we run two ablations of identical size and strength that differ only in which features are removed.

  • (A) Circuit ablation — suppress all 180 shared-circuit features at strength −20.
  • (B) Matched null — suppress 180 random non-circuit features sampled from the same prompt's attribution graph (same stratified-by-activation procedure used for the specificity test; seed 7), at the same strength.

The evidence is the contrast between (A) and (B). If the circuit is faithful, removing it should break the task in a specific, mechanism-consistent way that removing a size- and strength-matched random set does not. And because the circuit is defined by recurrence across all five prompts, we run both ablations on all five — a result on one prompt could not justify the word "shared."

What a faithful-circuit failure should look like. If these 180 features implement the analogical computation, removing them should leave the model unable to complete "X is to Y as Z is to ___." The diagnostic prediction is that the model falls back to the template scaffolding it can still see — repeating the connective " to" — rather than emitting any candidate answer. A random ablation has no reason to fail in this particular way.

The discriminating signal is the failure mode: circuit ablation collapses every prompt to the template connective " to" at near-identical high confidence (logprob −0.026 to −0.030, σ = 0.0015), whereas the matched null scatters to idiosyncratic, mostly out-of-distribution tokens (a Polish word, a French word, a code identifier, a name) at far lower confidence (mean logprob −1.35). What the table shows, in two passes:

  • Necessity holds, but does not discriminate. Both (A) and (B) remove the correct answer on all 5/5 prompts. This confirms — across prompts, not by assumption — that at effective −80 you can derail the model by ablating 180 of anything. Necessity alone therefore cannot show that the circuit specifically matters.
  • Specificity lives in the failure mode. Circuit ablation produces a reproducible, near-deterministic collapse to the connective " to" — the same token at the same confidence (≈ −0.03) on all five prompts, across both geographic and semantic-role analogies. The matched null, facing the identical prompts at the identical magnitude, does not: it scatters to unrelated tokens at much lower confidence. Only one null run (Tokyo) lands on " to", and at 65× lower probability (−1.97 vs −0.03). The only variable differing between (A) and (B) is which features were removed — so the structured collapse is attributable to the circuit, not to the magnitude or count of the intervention.

This is the result that ties the §2.3 recurrence definition to a causal claim: the features that recur across analogies are the features whose removal — and only whose removal — makes the model fall back to the bare analogy template. The reproducibility across all five prompts is what licenses the word "shared."

One caveat, stated plainly. All five prompts end in the word "to," so "collapse to the connective" and "repeat the final prompt token" are the same observation. This is consistent with the relational-loss interpretation rather than contrary to it — losing the ability to complete the analogy is exactly what should leave the template connective as the only thing the model can still emit. And critically, the matched null faces the same "to"-final prompts yet does not reproduce the collapse, so prompt shape alone does not produce it. We also flag that −80 is a strong intervention: we read this experiment as evidence about which feature set carries the relational computation (via the failure-mode contrast), not as a surgical minimal-magnitude ablation. A strength titration locating the smallest intervention that separates circuit from null would sharpen the claim further (§5).

How causal weight is distributed inside the circuit (Berlin). The test above treats the 180 features as one set. To see the internal distribution, we additionally ablated each of the 180 features individually on the Berlin prompt. Only 24/180 (13.3%) shift the prediction on their own, and they concentrate sharply at the embedding layer (17 of 24 at L0 — 42.5% of L0 features tested, vs 5.0% at L1+). The circuit is therefore internally redundant: most single features are dispensable, and the individually load-bearing ones are early-layer template features (e.g. L0/11651, "the word 'to'"). This dovetails with the collective result — necessity lives in the set, not in most of its members. The full 180-row table is in Appendix A.2; we did not repeat this 180-call individual sweep on the other four prompts.

3.7.2 Phase 1 and Phase 2 Feature Necessity

A separate claim, a different object. §3.7.1 established that the recurring circuit is causally load-bearing as a whole. The paper makes a further, independent claim (§3.3): that the circuit is internally organized into three functional phases. Testing that organization is a question about a smaller, different set — a handful of hand-picked representative features per phase, not the full 180-feature circuit — so we test it with its own experiments here. Where §3.7.1 asked "is the recurring set causal?", §3.7.2–§3.7.3 ask "is it structured the way §3.3 describes?" These phase experiments also serve as the cross-domain check: they run on the semantic-role analogies (teacher, bird) as well as the geographic ones.

The three-phase architecture proposed in §3.3 — template parsing (Phase 1, L0–L4), analogy recognition (Phase 2, L5–L9), and relational integration (Phase 3, L10–L13) — is based on feature co-occurrence and semantic labels. To test whether these phases are causally necessary, we suppressed each of the 9 key phase features identified in §3.3 individually across all five prompts (9 features × 5 prompts = 45 tests).

Phase 1 results. L0/11651 ("the word 'to'") is the most causally important early-layer feature, necessary in 4/5 circuits. Its failure mode is diagnostic: suppressing it causes all three capital analogies to predict the city name itself (Berlin, Rome, Tokyo) rather than the target country. The model loses the "X is to Y as Z is to ___" template structure and instead completes with the most recently mentioned entity — it no longer recognizes the prompt as an analogy. Phase 2 results. The headline feature L5/5793 ("analogies") is never individually necessary in any circuit. Neither is L5/2141 ("comparisons of public figures"). For the fragile bird circuit (p=0.117), Phase 2 features are individually necessary: L8/13766 ("analogies or comparisons") changes "air" to "fish" — the model retrieves the source-domain animal instead of the target-domain habitat — and L9/13344 ("comparison between two things") changes "air" to "sky." These failures show that Phase 2 features contribute to relational mapping but are only individually critical when the prediction has minimal redundancy.

Phase 3 results. L13/10969 ("comparisons between disciplines") is not individually necessary for any circuit.

3.7.3 Collective Phase Suppression

The individual redundancy of Phase 2 features for high-confidence circuits raises the question: are they collectively necessary? We suppressed all features within each phase simultaneously, then tested combined Phase 1+2 and Phase 1+2+3 suppression.

Every cell is disrupted — all four experiments disrupt all 5 circuits (20/20).

Phase 2 collective suppression is the most informative experiment in this paper. Suppressing all four Phase 2 features simultaneously disrupts all 5 circuits — including the high-confidence capital analogies (p>0.97) that were immune to every individual Phase 2 suppression. The failure mode is striking and consistent: all three capital analogies predict "France" — the source country — instead of the target country. The model retains the factual association "Paris is to France" and completes with "France" because it can no longer compute the relational transfer "as X is to ___." It echoes the source pair's answer rather than mapping to the target pair. This is direct causal evidence that Phase 2 features collectively implement the relational transfer operation — the core of analogical reasoning — rather than merely detecting the analogy template.

Phase 1 collective suppression produces empty outputs for all three capital analogies — the model cannot even generate a coherent token. For the semantic role analogies (teacher, bird), it produces "to" — the model is stuck on the syntactic connective it can no longer parse. This is a more severe failure than Phase 2 suppression, consistent with Phase 1 (template parsing) being a prerequisite for Phase 2 (analogy recognition).

Combined Phase 1+2 suppression produces ":" for 4/5 circuits. This punctuation output mirrors the format-override failure documented in the linguistic analysis (§4.5 of the expanded paper), where the model's format-completion circuit outcompetes the semantic-retrieval circuit. With both template parsing and analogy recognition disabled, the prompt resembles a list header ("Paris is to France as Berlin is to:") and the model defaults to list-formatting punctuation.

These results establish a causal hierarchy: Phase 1 (template parsing) → Phase 2 (relational transfer) → Phase 3 + late layers (entity selection). Each phase is collectively necessary, and earlier phases are prerequisites for later ones.

What this ledger does not claim. Three honest bounds. (i) Sufficiency. We show the circuit is necessary and fails in the predicted way; we do not show it is sufficient to generate the answer in isolation. The single-feature sufficiency probe we ran (Appendix A.4) was largely negative — the highest-influence hub feature induces the target only when the target entity is already present in the prompt. (ii) Surgical necessity. As a minor convergence check, the single feature L0/11651 ("the word 'to'") is flagged as causally important by both the circuit test (§3.7.1, where it is one of the 24 individually-disrupting features) and the phase test (§3.7.2, necessary in 4/5 circuits). Since it belongs to both candidate sets these are overlapping rather than independent designs, but the same template-collapse failure mode recurs under both — consistent with its role as the connective the model falls back on.

4. Discussion

4.1 The Analogical Reasoning Circuit in Gemma-2-2B

Our analysis reveals that Gemma-2-2B implements analogical reasoning through a distributed circuit spanning all 26 transformer layers, with specific functional specialization. The most significant finding is the existence of explicitly semantic analogy features at layers 5, 8, 9, and 13 — features that Neuronpedia's automated explanation system describes using the words "analogies," "comparisons," and "relationships between concepts." The presence of these features suggests that the model has internalized the concept of analogical structure as a discrete, reusable computational primitive, rather than computing analogies purely through implicit pattern matching.

4.2 The Role of Formal Text Features

The high-recurrence "code and legal text" features (L4 #14857, L6 #2267, L3 #3205) present an intriguing puzzle. We propose two complementary interpretations:

  • Functional hypothesis: These features detect formal, template-driven text patterns. The analogy syntax "X is to Y as Z is to" is highly formal and structured, resembling legal definitions, code comments, and mathematical notation. The model reuses a general "formal syntax" detector.
  • Training data hypothesis: The analogy format "A is to B as C is to D" appears frequently in SAT prep, vocabulary building, and educational texts — which also contain code examples and legal definitions, creating a statistical association between formal-text features and analogy-completion contexts.

Both are compatible with the data. The co-occurrence of formal-text features (even higher appearance counts) with true analogy features (lower counts, higher specificity) supports interpretation 1: the formal features process the syntax while the analogy features process the relational semantics.

4.3 Cross-Domain Generalization

The consistent activation of the same core features — especially L5 SAE#5793 "analogies" and L8 SAE#13766 "analogies or comparisons" — across both capital-city and semantic-role analogy types provides evidence for a domain-general analogical reasoning mechanism. The slightly larger graphs for semantic-role analogies (teacher, bird) may reflect that these completions require broader world knowledge access — knowing that teachers work in schools, or that birds inhabit air/sky — rather than purely relational computation.

4.4 Comparison with the Capital City Recall Circuit

Comparing with the capital city factual recall circuit (prompt: "The capital of X is") reveals:

  • Overlap: L4 #14857 ("code snippets") and L6 #2267 appear with high frequency in both circuits — these features are activated by formal definitional prompts generally, not specific to either task.
  • Divergence: The L5 "analogies" feature and L8 "analogies or comparisons" feature appear to be specific to the analogical task — they were not among the top recurring features in the factual recall circuit. This supports the interpretation that these features are selectively activated by relational structure recognition, not by factual recall.
  • Architecture: Both circuits exhibit layer-spanning computation with early structural processing and later semantic integration, but the analogy circuit shows unique mid-layer (L8–L9) analogy-detector features absent from the factual recall circuit.

5. Limitations

  1. SAE-feature-level intervention only. Steering operates at the SAE feature level, not the attention head or residual stream level. The causal role of non-SAE circuit components (attention patterns, MLP neurons, residual stream directions) is not assessed. Additionally, while we tested individual and collective phase suppression, combinatorial interactions between specific feature subsets were not exhaustively explored.
  2. SAE coverage. The gemmascope-transcoder-16k SAE covers only cross-layer transcoder features. Attention head contributions and residual stream features are not captured in this analysis.
  3. Threshold sensitivity. Results are sensitive to the node and edge thresholds set during graph generation (0.80 and 0.85). Lower thresholds would reveal more features; higher thresholds would produce sparser, more focused circuits.
  4. Label quality. Neuronpedia's automated feature explanations are LLM-generated and may not perfectly capture feature semantics. The "code snippets" label for L4 #14857 may underspecify a broader "formal structured text" concept.
  5. Prompt set size. Five prompts are sufficient for initial circuit identification but too few to claim statistical robustness. A larger prompt set covering more analogy types would strengthen conclusions.
  6. Necessity and failure mode are shown; sufficiency is not. The circuit-level tests (§3.7.1, all five prompts) establish that the recurring circuit is necessary and that removing it produces a specific, predicted failure mode — but not that the circuit is sufficient to generate the answer in isolation. Our only sufficiency probe boosts a single hub feature (Appendix A.4) and is largely negative. A clean circuit-level sufficiency test — patching the circuit's collective activation into a non-analogy context — is beyond what the per-feature steering API supports and remains future work. Separately, the one-at-a-time individual necessity sweep (§3.7.1, internal structure) was run on Berlin only; the circuit-vs-null contrast that carries the main claim covers all five prompts.
  7. Steering at large effective magnitude is not feature-clean. The Neuronpedia API multiplies the bare strength parameter by 4, so "strength −20" produces an effective −80 intervention into each feature's decoder direction. The matched null control (§3.7.1, Appendix A.6) shows that ablating any 180 features at this magnitude removes the prediction — the substantive circuit-vs-non-circuit distinction is the failure mode (the reproducible, high-confidence collapse to the template connective " to" vs idiosyncratic out-of-distribution tokens), not whether the prediction survives. Until a strength-titration analysis identifies a minimum effective intervention that isolates feature-specific effects from generic residual-stream perturbation, these results should be read as evidence about mechanism-consistent degradation rather than about uniquely-necessary feature sets.

6. Conclusions

We have identified and characterized the analogical reasoning circuit in Gemma-2-2B using SAE attribution graphs from the Neuronpedia platform. The key conclusions are:

  1. A stable shared circuit exists. 180 features are active across all five tested analogy prompts, and 510 across at least three, demonstrating a consistent internal mechanism for analogy completion.
  2. Dedicated analogy features exist at layers 5, 8, 9, and 13. These features have Neuronpedia explanations explicitly referencing analogies, comparisons, and relational concepts — providing the first direct evidence of interpretable analogy-concept features in a large language model.
  3. The circuit exhibits a three-phase architecture. Template parsing (L0–L4), analogy recognition (L5–L9), and relational integration (L10–L13), with activation magnitude increasing through the sequence.
  4. Cross-domain generalization is confirmed. The same core features, including the literal "analogies" feature (L5 SAE#5793), activate for both geographic and semantic role analogies — suggesting a domain-agnostic relational reasoning primitive.
  5. Formal-text features co-activate. High-recurrence features encoding "code" and "legal text" patterns reflect the formal syntax of the analogy template activating domain-general structured-text detectors.
  6. Causal steering supports the shared circuit and the three-phase architecture across all five prompts. Ablating the 180-feature shared circuit collapses every analogy prompt to the template connective " to" at near-identical high confidence (logprob −0.03, 5/5), whereas a size- and strength-matched random non-circuit ablation produces idiosyncratic, lower-confidence out-of-distribution tokens (§3.7.1; per-prompt detail in Appendix A.6). Because the two interventions are matched in count and strength, the structured collapse is attributable to which features were removed — the recurring circuit — not to the magnitude of the perturbation. Within the circuit, individual-feature necessity (Berlin) concentrates sharply at L0 template features (17/24). The Phase 2 collective-suppression experiment, run across all five prompts, causes capital analogies to revert to the source-pair country ("France") — the signature of lost relational transfer (§3.7.3). §3.7.4 collects these into a claim-by-claim ledger: the shared circuit is causally necessary and fails in the predicted way (demonstrated), its three-phase organization holds (demonstrated), and generalization across geographic and semantic-role analogies is supported; circuit-level sufficiency is not established and remains future work (§5).

A.1 Methodology and Reproducibility

Circuit definition. The 180-feature shared analogical circuit (defined in §2.3) consists of all transcoder features that appear in ≥5 nodes across the five analogy attribution graphs (Berlin, Rome, Tokyo, teacher, bird), where node count is the total number of (feature, token-position) instances. A given feature can fire at multiple token positions in a single graph, and across multiple graphs; the threshold ≥5 captures features that are recurringly relevant to analogical reasoning rather than incidental to a single prompt. The circuit is heavily early-layer biased: 40 features at L0, 16 at L1, 13 at L2, 18 at L3, 20 at L4, 20 at L5, 16 at L6, and decreasing density at L7+. The full feature list is provided as analogical_circuit_180features.json.

Steering API parameters. All experiments use the Neuronpedia /api/steer endpoint with:

  • modelId: "gemma-2-2b"
  • layer: "{layer}-gemmascope-transcoder-16k" (layer-prefixed SAE identifier — using the global SAE name returns HTTP 404)
  • strength_multiplier: 4 (global; effective per-feature strength = strength × 4)
  • temperature: 0, seed: 42, n_tokens: 5 per call
  • strength: -20 for ablation, +20 for boost

Execution. The Neuronpedia API rate-limits steering at 120 calls per rolling 60-minute window. The Berlin individual-necessity sweep (180 calls) and the single-feature side-tests (A.3, A.4) were run as the original battery across two windows; the circuit-level cross-prompt tests (§3.7.1: 5 prompts × {circuit ablation, matched null} = 10 calls) were run separately and well within one window. The 180-feature payload intermittently returns HTTP 500 under load even though the identical call succeeds on retry; the cross-prompt runner retries 500s with backoff (two calls — Rome and Bird circuit ablation — required a retry). Baseline (unsteered) continuations are read from the default_text field returned with every steering call, since the model receives the same prompt with no steering on the default branch; a dedicated empty-features baseline call returns HTTP 500 (a server-side quirk of the empty payload) and is not needed.

Failure mode classification. A feature is marked "disrupted" if and only if (a) the API call succeeded and (b) the substring "germany" (case-insensitive) does not appear in the steered output text. Both checks are conservative: we never count a network error as a disruption, and we count any continuation that drops " Germany" as a disruption regardless of how plausible the alternative is.

Specificity sampling. Non-circuit features are sampled from the analog_berlin attribution graph (789 transcoder features total). Sampling excludes features in the 180-feature circuit (matched by (layer, local_index) tuple), then stratifies the remainder into four activation bands and samples uniformly within each band using random.Random(42). The intention is to sample features comparable in salience to the circuit features themselves rather than only sampling features the circuit definition would have already excluded as low-magnitude.

A.5 Comparison with Per-Prompt Causal-Path Backbones

Earlier versions of this paper used a per-prompt backbone definition: features on the top-5 forward + top-5 backward causal paths from the embedding nodes to the logit, traced separately for each prompt. The 180-feature shared circuit (this paper) is a different, broader definition: features that recur across multiple analogy graphs, regardless of whether they sit on the top causal paths in any single prompt. The two definitions are complementary:

  • The per-prompt backbone contains 4–10 features per circuit, dominated by late-layer (L17+) entity-specific drivers like L25/4717 and L25/286. It captures the prompt-specific computation.
  • The 180-feature shared circuit contains 180 features, dominated by early-layer (L0–L6) features that recur because all five analogy prompts share the same template structure. It captures the prompt-general analogy machinery.

Sufficiency is the test for which the shared-circuit definition is least suited: late-layer entity-specific drivers (selected by per-prompt backbone) carry stronger sufficiency signal than the early-layer template features (selected by recurrence). Necessity and specificity behave similarly under both definitions. Full suppression behaves differently: the shared-circuit collapse to " to" appears mechanism-specific only when read against the null control in §A.6 (180 random non-circuit features ablated at the same strength produce a different, unstructured collapse) — without that null, "180 features ablated together disrupts the prediction" is not by itself a stronger statement than the equivalent per-prompt-backbone result.

A.6 Circuit Ablation vs. Matched Null — Per-Prompt Detail

This is the per-prompt detail behind Table 3.7.1A. For each of the five analogy prompts we run two ablations at strength −20 (effective −80 per feature): (A) suppress all 180 shared-circuit features (identical set for every prompt); (B) suppress 180 random non-circuit features sampled from that prompt's own attribution graph using the stratified-by-activation procedure of A.3 with seed 7. Baselines are the unsteered (default_text) branch returned with each call. The two design choices that make (B) a fair control: it matches (A) in count (180) and strength (−80), and it draws from the same graph so the features are ones actually active on that prompt.

Circuit ablation (highlighted) drives every prompt to repeat the connective " to" at near-identical confidence (logprob −0.026 to −0.030 across all five; σ = 0.0015). Matched null drives the model to idiosyncratic, mostly out-of-distribution tokens — autorytatywna (Polish), espère (French), initComponents (a code identifier), Kyrie (a name) — at much lower and highly variable confidence (logprob −0.32 to −2.84, mean −1.35). What this establishes. Both ablations remove the correct answer on all five prompts, so necessity at this strength is real but non-discriminating. The discriminating signal is the failure mode: only circuit ablation produces the reproducible, high-confidence collapse to the analogy template's connective, and it does so identically across three geographic and two semantic-role analogies. Since (A) and (B) are matched in count, strength, and source graph, the structured collapse is attributable to which features were removed — the recurring circuit — not to the magnitude of the intervention. This is the cross-prompt evidence underpinning row 1 of the §3.7.4 ledger.

Caveat (also noted in §3.7.1). Every prompt ends in "to," so "collapse to the connective" coincides with "repeat the final token." This is consistent with relational-completion loss, and the matched null faces the same "to"-final prompts without reproducing the collapse, so prompt shape alone does not explain it; but a strength titration would be required to claim a minimal/surgical ablation.
