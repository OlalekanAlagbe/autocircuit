Introduction: The Analogical Reasoning Challenge

The Task

Complete the analogy:

"Paris is to France as Berlin is to ____"

Expected: "Germany"

The Core Question

Does the model perform genuine two-step relational reasoning — identifying the capital-of relationship and applying it compositionally — or does it rely on a statistical shortcut?

Why This Is Hard

  • Requires recognizing a relational structure, not just recalling a fact
  • Must separate "capital-of" from specific cities and countries
  • Must apply the relation compositionally to unseen pairs
  • Must generalize across domains: geographic, professional, biological

Prior Work Gap

Mechanistic interpretability has illuminated factual recall circuits (Meng et al. 2022) and syntactic processing (Conmy et al. 2023), but analogical reasoning — relational abstraction — remains unexplored at the circuit level.

Introduction: Situating This Work

What We Know From Prior Work

FACTUAL RECALL CIRCUITS

Meng et al. (2022) localized factual associations to specific MLP layers. "The capital of France is Paris" retrieves a stored pair.

INDIRECT OBJECT ID

Wang et al. (2022) traced IOI through attention heads. Clean compositional binding of syntactic roles.

The Analogical Gap

Analogies demand more: not recall of which city, but recognition of the abstract capital-of relation — and its compositional transfer. This is qualitatively different from previously analyzed circuits.

We apply SAE attribution graphs (Bricken et al. 2023; Anthropic 2025) to directly trace how the "capital-of" abstraction flows through Gemma-2-2B's layers.

Our Contribution

First mechanistic analysis of analogical reasoning using SAE attribution graphs. We identify a cross-domain analogical circuit with interpretable, semantically labeled features at each computational stage.

Research Questions

1

Shared Circuit or Multiple Mechanisms?

Does Gemma-2-2B use a single circuit for all analogy types, or separate mechanisms for geographic vs. semantic role analogies?

2

Most Consistent Features?

Which SAE features recur most reliably across five structurally diverse analogical prompts?

3

Semantically Interpretable Analogy Features?

Are there discrete features that encode the abstract relational structure of analogies — separate from domain-specific knowledge?

4

How is the analogical computation distributed across the 26 transformer layers of Gemma-2-2B?

Methodology: Cross-Graph Feature Analysis

Core Idea: Shared Circuit Identification

A feature is identified by its (layer, SAE index) pair. We compute which features appear across multiple graphs to isolate the computations common to all analogy types.

Overlap Thresholds

≥ 3/5 graphs
Broad circuit — captures even domain-specific features that partially generalize
≥ 4/5 graphs
Robust circuit — filters noise, retains strong generalizers
5/5 graphs

Feature Labeling

Top 25 recurring features were labeled via:

GET /api/feature/{model}/{layer}-{sae}/{index}

Labels are LLM-generated descriptions of what each SAE feature activates on, providing semantic interpretability.

Key finding: The SAE ID must be layer-prefixed. Using the global name returns HTTP 500.

Results: Cross-Domain Generalization

The same core features activate for geographically-specific and semantically-open analogies — evidence of a domain-agnostic relational mechanism.

Capital-City Analogies

  • Berlin, Rome, Tokyo prompts
  • Nodes: 905–963 (smaller graphs)
  • Well-defined factual output domain
  • L5 "analogies" feature active ✓
  • L8 "analogies or comparisons" active ✓
  • Some L6–L7 geographic features unique to this type

Semantic Role Analogies

  • Teacher, Bird prompts
  • Nodes: 1,040–1,071 (larger graphs)
  • Ambiguous output domain (school? sky?)
  • L5 "analogies" feature active ✓
  • L8 "analogies or comparisons" active ✓
  • Broader world-knowledge access required

The Shared Core (180 features, all 5 prompts)

The explicitly analogical features — L5#5793 "analogies" and L8#13766 "analogies or comparisons" — appear in this shared core. This provides strong evidence that Gemma-2-2B uses a domain-agnostic analogical reasoning circuit rather than separate mechanisms for geographic vs. semantic analogies.

The larger graphs for semantic role analogies likely reflect greater world-knowledge retrieval breadth, not a fundamentally different relational mechanism.

Results: The Formal-Text Co-Activator Puzzle

Three features with the highest recurrence counts have labels unrelated to analogical reasoning — but their presence is interpretable.

FeatureAppearancesAvg InfluenceLabel
L4 SAE#1485722/50.681 "code snippets and license agreements"
L6 SAE#226720/50.724 "words in programming code, legal jargon, or scientific texts"
L3 SAE#320520/50.670 "code snippets and documentation references"

Hypothesis 1: Formal Syntax Detector

The analogy syntax "X is to Y as Z is to" is highly formal and template-driven — resembling legal definitions ("A is defined as..."), code comments, and scientific notation. The model reuses a general "formal structured text" detector for these structural roles.

Hypothesis 2: Training Data Co-occurrence

The analogy format appears in SAT prep and vocabulary texts — which also contain code, legal definitions, and scientific documentation. A spurious statistical association in training creates this co-activation.

Key diagnostic: These features have higher appearance counts (20–22) than the semantic analogy features (11–21), suggesting they fire broadly at multiple context positions — consistent with syntax detection rather than selective relational understanding.

Discussion: A Domain-General Analogical Reasoning Primitive

The Core Finding

Gemma-2-2B implements analogical reasoning through a distributed circuit spanning all 26 transformer layers, with specific functional specialization at each phase. The existence of features explicitly labeled "analogies," "analogies or comparisons," and "comparisons between disciplines" suggests the model has internalized analogical structure as a discrete, reusable computational primitive — rather than computing analogies purely through implicit pattern matching.

Implications

  • Analogy completion is qualitatively different from factual recall — different mid-layer features are uniquely engaged
  • The analogy circuit is not merely "factual recall applied twice" — dedicated relational detectors exist
  • Cross-domain generalization is mechanistically grounded: one circuit, multiple semantic domains
  • The three-phase architecture may generalize to other relational reasoning tasks

Discussion: Limitations & Future Work

Limitations

No causal validation. All 30 steering experiments returned HTTP 404 — the gemmascope-transcoder-16k SAE is not supported for feature steering via the public API. Identified features are correlated with correct completion, not confirmed as causally necessary.
SAE coverage. The transcoder SAE captures cross-layer features; attention head contributions and residual stream features are not included.
Threshold sensitivity. Results depend on node (0.80) and edge (0.85) thresholds. Lower thresholds would reveal more features; higher thresholds produce sparser circuits.
Label quality. Neuronpedia labels are LLM-generated and may underspecify feature semantics (e.g. "code snippets" may mean "formal structured text").
Prompt set size. Five prompts provide initial circuit evidence but insufficient statistical robustness.

Future Work

  • Causal validation via activation patching and zero-ablation using TransformerLens
  • Expanded prompt set: arithmetic analogies (3:9::4:?), linguistic analogies (synonyms, antonyms), cross-lingual analogies
  • Attention head analysis to identify heads contributing to relational binding
  • Cross-scale comparison: Gemma-2-9B, Gemma-2-27B — does the circuit scale or reorganize?
  • Negative controls: Attribution graphs for non-analogy prompts of similar length
  • Cross-model comparison: GPT-2, Pythia — is the three-phase architecture universal?
  • Inhibition experiments: Suppress L5 SAE#5793 ("analogies") and measure impact on completion accuracy

Conclusions

1

A stable shared circuit exists: 180 features are active across all five analogy prompts, and 510 across at least three — Gemma-2-2B employs a consistent internal mechanism for analogy completion.

2

Dedicated analogy features discovered at layers 5, 8, 9, and 13: Features with explanations explicitly referencing "analogies," "comparisons," and "relationships between concepts" — the first direct evidence of interpretable analogy-concept features in a large language model.

3

Three-phase circuit architecture confirmed: Template parsing (L0–L4) → Analogy recognition (L5–L9) → Relational integration (L10–L13), with activation magnitude building through the sequence.

4

Cross-domain generalization confirmed: The literal "analogies" feature (L5 SAE#5793) activates for both geographic and semantic role analogies — a domain-agnostic relational reasoning primitive.

5

Formal-text features co-activate: High-recurrence features encoding "code" and "legal text" patterns reflect the formal syntax of the analogy template activating domain-general structured-text detectors.

6

Causal validation outstanding: Steering experiments failed due to API limitations. Future work with TransformerLens activation patching is required to confirm causal necessity of the identified features.
