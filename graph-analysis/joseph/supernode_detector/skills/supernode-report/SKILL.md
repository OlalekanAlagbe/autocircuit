# Supernode Report

Generate or review a detailed analysis report from a supernode detection pipeline run.

## Overview

This skill reads the pipeline outputs and produces (or reviews) a comprehensive analysis:
- Reads `supernode_report.md` generated by the pipeline
- Reads `annotated_graph.json` for structural data
- Reads `community_visualization.png` for visual reference
- Summarizes findings: communities, bottlenecks, information flow

## Instructions

### 1. Locate the pipeline output

```bash
ls supernode_detector/output/
```

Select the relevant output directory: `output/{model}_{prompt_slug}/`

### 2. Read the supernode report

```bash
cat supernode_detector/output/{model}_{prompt_slug}/supernode_report.md
```

The report contains:
- Prompt and model info
- Community detection results (algorithm, modularity, partition)
- Per-community breakdown (size, layers, key features, labels)
- Bottleneck nodes with betweenness centrality scores
- Trimming summary (nodes before/after)

### 3. Read the annotated graph for additional data

```bash
python -c "
import json
with open('supernode_detector/output/{model}_{prompt_slug}/annotated_graph.json') as f:
    data = json.load(f)
supernodes = data.get('qParams', {}).get('supernodes', {})
for name, members in supernodes.items():
    print(f'{name}: {len(members)} nodes')
print(f'Pinned bottlenecks: {len(data.get(\"qParams\", {}).get(\"pinnedIds\", []))}')
"
```

### 4. Report to user

Summarize:
- **Model & Prompt**: What was analyzed
- **Communities**: Number, sizes, layer spans, semantic labels
- **Bottlenecks**: Critical routing nodes and their centrality
- **Information Flow**: How information moves through the circuit (early -> mid -> late layers)
- **Key Findings**: Notable patterns (e.g., layer concentration, cross-community connections)
- **Neuronpedia Link**: If previously uploaded

## Key Metrics to Highlight

1. **Modularity score** -- How well-separated the communities are (>0.3 is good, >0.5 is excellent)
2. **Largest community ratio** -- If one community has >30% of nodes, it was recursively split
3. **Bottleneck centrality** -- Higher betweenness = more critical routing node
4. **Layer concentration** -- Which layers dominate each community
5. **Trimming ratio** -- What fraction of nodes was retained (default 15%)

**User**: "What did the Titanic analysis find?"

## Common Issues

- **"No output directory found"**: Run `/supernode-pipeline` first
- **"Report file missing"**: The pipeline may have failed partway through -- check for `raw_graph.json` at minimum

## When to Use

- After running `/supernode-pipeline`
- User asks to "summarize" or "explain" an analysis
- User wants to understand circuit structure
- Preparing findings for a presentation or paper
- Comparing multiple prompt analyses

## Feature ID Reference

- **Feature ID mapping**: `neuronpedia_id = circuit_tracer_id % 16384`
- **GEMMA SAE path**: `{layer}-gemmascope-transcoder-16k`
- Feature pages: `neuronpedia.org/gemma-2-2b/{layer}-gemmascope-transcoder-16k/{neuronpedia_id}`
