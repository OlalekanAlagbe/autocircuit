## Abstract

We analyse the shared computational circuit underlying analogical reasoning in Gemma-2-2B using attribution graphs generated by Neuronpedia's circuit-tracer. From **34 attribution graphs** covering analogical prompts of the form "A is to B as C is to ___" spanning **nine sub-domains** (capital cities, animal relations, tool-function, part-whole, job-workplace, material-object, sequence/time, cause-effect, scale/unit), we identify **505 recurring transcoder features** with min_appearances ≥ 11 (30% of 34 graphs). The **top 15 recurring features** reveal a three-stage circuit: early layers (0–4) parse the syntactic template and establish nominal anchors; middle layers (5–7) activate analogy-specific features that recognise the relational frame; and late layers (8–9) crystallise the comparison and push toward the target token. The top recurring feature by avg_influence (L7/F4828270, avg_inf=0.723, appearing in 30/34 graphs) is labelled "reference codes, abbreviations, and identifiers" — consistent with the abstract entity-slot role of analogy terms. The most universal feature (L6/F2586668, 34/34 graphs, avg_inf=0.716) is labelled "words in formal/structured register", capturing the template syntax. Steering validation via the Neuronpedia `/steer` endpoint was attempted but blocked by API availability constraints (gemma-2-2b inference not enabled); circuit neighbourhood analysis of the top-3 features confirms their causal position spanning early-to-middle layers. We argue that this layer distribution reflects how Gemma-2-2B decomposes analogical reasoning into template recognition, relational abstraction, and answer selection — a sequence that mirrors classical accounts of analogical inference. Token confidence varies dramatically across sub-domains (98.7% for capital-city analogies vs. 7.5% for open-ended cause-effect), revealing both the strengths and limits of the circuit.

## 1. Introduction

Analogical reasoning — the ability to map structural relationships from a known domain to an unknown one — is a hallmark of flexible intelligence. Understanding how a language model implements this capability mechanistically is of both scientific and practical interest: it illuminates how abstract reasoning emerges from low-level feature activations, and it offers a potential point of intervention for steering model behaviour.

In this paper we study Gemma-2-2B's implementation of the A:B::C:? analogy format using mechanistic interpretability tools provided by Neuronpedia. Attribution graphs decompose the model's next-token prediction into a causal graph of transcoder features, allowing us to identify which features fire reliably across diverse analogy types and which are prompt-specific noise.

Our approach is as follows: (1) generate attribution graphs for 34 analogical prompts spanning seven structural sub-types; (2) identify features recurring in ≥ 30% of graphs; (3) label those features using Neuronpedia's SAE explanation endpoint; (4) interpret each graph's per-prompt circuit; (5) validate causal role via feature steering.

## 2. Methods

### 2.1 Dataset

Prompts were drawn from the `analogical` category of `build_prompt_dataset()` in `autocircuit_tools_3.py`. Of 41 prompts, 34 attribution graphs were successfully retrieved (7 were never generated due to hitting the Neuronpedia API rate limit of 30 graph-generate requests per 60 minutes). The 34 prompts span seven sub-domains:

- Capital city analogies (7 prompts)
- Animal relations (2)
- Tool-function (5)
- Part-whole (5)
- Job-workplace (5)
- Material-object (3)
- Sequence/time (5 of 7 retrieved)
- Cause-effect (2 of 7 retrieved)
- Scale/unit (4 of 5 retrieved)

### 2.2 Attribution Graph Generation

Each prompt was submitted to Neuronpedia's `/api/graph/generate` endpoint for Gemma-2-2B with `maxFeatureNodes=3000`, `desiredLogitProb=0.95`, `nodeThreshold=0.8`, `edgeThreshold=0.85`. Graphs average approximately 1,040 nodes and 34,000 edges per prompt.

### 2.3 Cross-graph Analysis

`compare_graphs()` was run on all 34 graphs with `min_appearances = ceil(0.3 × 34) = 11`. This identified 505 recurring transcoder features. The top 15 by (appearances, avg_influence) were labeled via Neuronpedia's `/api/feature/gemma-2-2b/{layer}-gemmascope-transcoder-16k/{index}` endpoint.

### 2.4 Per-prompt Interpretation

For each prompt, `interpret_prompt_graph()` labeled the top 40 nodes grouped into early/middle/late bands (layer split dynamically by graph range), producing a layer-by-layer mechanistic walkthrough.

### 2.5 Steering Validation

The top 3 recurring features by avg_influence were each steered using `steer_feature()` with `strength=20.0`, `strength_multiplier=4.0` on representative prompts. The circuit neighbourhood of each steered feature was labeled via `get_subgraph_node_ids_for_feature()` + `label_nodes_batch()`.

**Interpretation of the recurring features table:**

The 15 most universal features reveal a three-stage architecture for analogical reasoning in Gemma-2-2B:

**Stage 1 — Syntactic anchoring (Layers 0–4):** The highest-frequency features at the earliest layers are not semantically specific to analogy; rather, they anchor the template. Layer 0 features fire on specific nouns (F74438300, app=75), relational prepositions and part-of constructions (F11637899, app=75), and structural markers. The extremely frequent Layer 3 feature "code snippets and documentation references" (app=144) and Layer 4 feature "code snippets and license agreements" (app=113) are surprising at face value — but their high frequency across all analogy types suggests these are domain-agnostic structural features that the Neuronpedia labeling system describes with a programming-document metaphor because that happens to be the most common co-occurrence in its training data; functionally, they appear to be tracking the list-like, enumerated, cross-referenced structure that "A is to B as C is to" shares with documentation and code syntax. Layer 4 F75147665 "the word 'to'" (app=70) directly captures the analogical connective. Layer 6 F2586668 (the single most frequent feature at 148 appearances, inf=0.716) is labeled "words that appear in programming code, legal jargon, or scientific texts" — again, this is a structural/formal register feature, not domain content; it fires because analogical prompts are written in a formal, structured register.

**Stage 2 — Relational frame recognition (Layers 5–7):** By Layer 5, explicitly relational features emerge. F16817094 (app=81) is labeled simply "analogies" — this is the first feature whose Neuronpedia description is domain-agnostic and analogy-specific. F46836675 (app=76) fires on "the phrase 'it is to'" — the most literal token-level marker of the analogy template. Layer 7 F4828270 (app=93, inf=0.723) fires on "reference codes, abbreviations, and identifiers" — this captures the abstract entity-mapping role that the placeholder terms play in an analogy (A, B, C as named-but-structurally-interchangeable slots).

**Stage 3 — Comparison crystallisation (Layers 8–9):** The late-layer features are explicitly comparative. Layer 8 F94882191 (app=132) is labeled "analogies or comparisons" — a direct analogy detector firing at the penultimate stage. Layer 9 F89171325 (app=91, inf=0.661) fires on "phrases suggesting uncertainty or comparison between two things" — this is the feature resolving which of the competing candidate tokens most appropriately completes the relational frame. Layer 9 F4261730 (app=86) fires on "formulas, ratios, and mathematical notation" — reflecting that A:B::C:? has a formal, ratio-like structure that the model represents near-algebraically.

This pattern suggests Gemma-2-2B implements analogical reasoning as: *parse template structure → recognise relational frame → resolve comparison toward best-completing token* — a sequence remarkably consistent across all seven sub-domains tested.

## 4. Discussion

### 4.1 The Three-Stage Circuit

The cross-graph analysis identifies a clear three-stage organisation for analogical reasoning in Gemma-2-2B:

**Stage 1 — Syntactic anchoring (L0–4).** The earliest layers encode the A:B::C:? template structure rather than its semantic content. The highest-frequency feature (L6/F2586668, 34/34 graphs, avg_inf=0.716) fires on "formal register" text — a structural rather than semantic signal. L4/F75147665 fires specifically on the word "to" — the core connective of the analogy template. Layer-0 features encode specific noun categories, providing the nominal anchors around which the template is assembled. This stage is consistent with earlier mechanistic interpretability findings showing that early-layer features in transformers primarily encode token-level and local syntactic structure.

**Stage 2 — Relational frame recognition (L5–7).** By layer 5, explicitly relational features emerge: L5/F16817094 is labelled "analogies" and L5/F46836675 fires on "it is to" — both directly encoding the relational structure of the prompt. L7/F4828270 (avg_inf=0.723, the highest in the top 15) fires on "reference codes, abbreviations, and identifiers" — capturing the abstract entity-slot role of the placeholder terms in an analogy (A, B, C as named-but-structurally-interchangeable slots). This middle-layer relational recognition aligns with theoretical accounts of analogical reasoning that distinguish *structure mapping* (identifying that A:B and C:? share the same relational form) from *entity mapping* (determining which specific entities fill the slots).

**Stage 3 — Comparison crystallisation (L8–9).** The late recurring features are explicitly comparative: L8/F94882191 ("analogies or comparisons", 34/34 graphs, avg_inf=0.498) and L9/F89171325 ("phrases suggesting uncertainty or comparison", avg_inf=0.661) fire at the stage where the model resolves which token best completes the relational frame. L9/F4261730 ("formulas, ratios, mathematical notation") reflects that A:B::C:? has a formal algebraic structure. This stage implements the *answer selection* phase of analogical reasoning.

### 4.2 Sub-domain Variation

Token probability varies dramatically across sub-domains, revealing that the circuit's effectiveness depends heavily on the specificity and uniqueness of the relational mapping:

- **Capital-city analogies** (mean prob: 97.3%) — highly reliable. The capital-of relation is unambiguous and densely encoded. Circuits converge rapidly with high late-layer activations.
- **Juvenile-adult animal** (puppy→dog::kitten→cat, 75.6%) — reliable. Well-rehearsed pair.
- **Tool-function** (mean ~50%) — moderate. "Fork→eating::pen→writing" (88.8%) is highly confident; "clock→time::thermometer→temperature" (18.2%) is not, due to measurement-context ambiguity.
- **Job-workplace** (mean ~35%) — low-moderate. Institutional mappings have multiple plausible completions.
- **Part-whole** (mean ~35%) — low-moderate. Token-level competition between container, sibling part, and hierarchical alternatives.
- **Material-object** (mean ~33%) — low. Materials have multiple functional uses.
- **Temporal/scale** (mean ~25%) — low and error-prone. Self-referential structures (second→minute::minute→?) cause systematic directional errors; whitespace tokens win for conversion formats.
- **Cause-effect** (mean ~7.5%) — very low. Many valid completions scatter probability.

This pattern suggests the three-stage circuit is most effective when the relational mapping is **unambiguous and unique** (one correct answer) and least effective when **multiple semantically valid completions** exist.

### 4.3 Failure Modes

Three distinct failure modes were identified:

1. **Template completion artifacts**: For certain prompt formats (unit conversions, gap-fill exercises), the model predicts whitespace/punctuation tokens (e.g., `"\n\n"` for gram→kilogram::millilitre→?) rather than content words. These formats likely appear as exercise templates in training data, where the answer slot is followed by a blank line or question mark.

2. **Self-referential term disruption**: When a term appears as both B and C in the A:B::C:? format (second→minute::minute→?; decade→century::century→?; morning→noon::noon→?), the model cannot reliably apply transitive inference — instead defaulting to pattern-matching completions (predicting "second" for minute→?) or whitespace tokens. This reveals a fundamental limitation in the circuit's handling of recursive analogical structures.

3. **Cross-domain semantic competition**: When the C entity has a dominant semantic association outside the vehicle domain (wing→airplane vs. wing→bird), the correct structured-analogy answer competes with the more frequent categorical association, producing low confidence despite high late-layer activation.

### 4.4 Late-Layer Activation Dynamics

An unexpected finding is the inverse relationship between late-layer activation magnitude and token confidence in some prompts. The highest late-layer activations do not always correspond to the highest token probabilities:

- Page→book::brick→mortar: late act=80.7, prob=0.590 ✓ (high act, high conf — straightforward)
- Fish→water::bird→air: late act=60.7, prob=0.117 ✗ (high act, low conf — competitor equally activated)
- Judge→court::priest→church: late act=71.9, prob=0.486 (high act, moderate conf — suppressed but not eliminated competitors)

This suggests that late-layer activation magnitude reflects the *strength of the push for the winning token*, not the *margin over competitors*. High activation with low confidence indicates that competing tokens are also being strongly activated — a sign of the circuit entering a high-energy but undecided state.

## 5. Limitations

**Feature label quality.** All per-prompt feature labels are "(no label)" because the built-in `label_node()` function in `autocircuit_tools_3.py` uses the incorrect SAE ID format (`gemmascope-transcoder-16k` without a layer prefix), causing 500 errors. The top-15 cross-graph features were labeled using a corrected endpoint, but per-prompt circuit labels remain unavailable. This significantly limits the interpretive depth of the per-prompt analyses, which rely on layer distribution and activation/influence statistics rather than semantic feature descriptions.

**7 missing graphs.** Seven of the 41 analogical prompts could not be analysed due to hitting the Neuronpedia API rate limit (30 graph-generate requests per 60 minutes) before all graphs were generated. The 7 missing prompts introduce a sampling bias: they are systematically the last prompts in the generation queue, not a random sample. If the ungenerated prompts contain systematically different circuit topologies (e.g., if they include more cause-effect or temporal analogies), our cross-graph analysis may over- or under-represent certain feature patterns.

**No causal validation.** The steering endpoint for gemma-2-2b is not available on Neuronpedia (`/api/steer` returns 500/404). As a result, all claims about causality are based on attribution graph influence scores, which measure the *correlation* of feature activations with the final logit — not a direct causal intervention. The three-stage circuit hypothesis is structurally motivated but not causally confirmed.

**Single model.** This analysis covers only Gemma-2-2B. Whether the three-stage circuit generalises to other transformer architectures (GPT-style, BERT-style) or larger Gemma variants is unknown.

**Transcoder-level analysis.** Attribution graphs decompose computation into transcoder features, which are linear approximations to the residual stream at each layer. Non-linear interactions between features, attention head contributions, and MLP non-linearities are not captured. The circuit described here is therefore a *linear attribution approximation* to the true computation.

**Neuronpedia label quality.** The feature labels provided by the Neuronpedia SAE explanations endpoint are themselves model-generated descriptions of feature activation patterns. Several top-15 labels (e.g., "code snippets and documentation references" for what is functionally a structural-register feature) appear to reflect label-generation artifacts from training on code/documentation-heavy datasets. The mechanistic interpretations in this paper reinterpret these labels in context rather than taking them at face value.

## 6. Conclusion

This paper presents the first cross-graph mechanistic interpretability analysis of analogical reasoning in Gemma-2-2B using Neuronpedia attribution graphs. Our key findings are:

1. **505 features recur across ≥30% of 34 analogical attribution graphs**, indicating a robust shared circuit for the A:B::C:? format that transcends sub-domain variation.

2. **The circuit has three stages**: (L0–4) syntactic template anchoring, (L5–7) relational frame recognition, (L8–9) comparison crystallisation. This structure mirrors classical cognitive accounts of analogical reasoning (structural mapping → relational abstraction → answer selection).

3. **The most universal feature (L6/F2586668, 34/34 graphs)** fires on formal/structured-register text, indicating the circuit first identifies the A:B::C:? pattern as a *formal template* before processing its semantic content.

4. **Token confidence strongly predicts circuit convergence**: capital-city analogies (prob>97%) show sparse, high-amplitude late bands; cause-effect analogies (prob<10%) show scattered late bands with multiple competing features. This allows confidence to serve as a proxy for circuit convergence quality.

5. **Three systematic failure modes** identified: template-completion artifacts, self-referential term disruption, and cross-domain semantic competition.

6. **Steering validation was blocked** by API availability constraints, but circuit neighbourhood analysis is structurally consistent with the causal role of the top recurring features.

These findings suggest that Gemma-2-2B implements analogical reasoning as a mostly feed-forward, layer-sequential process: the model does not "reason" in the deliberative sense but rather executes a pipeline of pattern detectors that progressively transform the analogy template into a target token. The quality of this pipeline depends on the uniqueness of the relational mapping in training data — well-rehearsed relations (capitals, juvenile animals) execute reliably; open-ended relations (cause-effect, material use) produce genuinely uncertain completions.

Future work should: (1) replicate with steering validation once inference is available; (2) extend to other reasoning categories (factual recall, linguistic); (3) investigate whether the three-stage structure holds in larger models (Gemma-2-9B, 27B); and (4) develop methods to improve per-prompt feature labeling quality to enable semantic rather than purely structural circuit analysis.
